# 🎓 Student Career & Performance Intelligence Dashboard

## 📌 Project Overview

The **Student Career & Performance Intelligence Dashboard** is a data analysis and visualization project designed to analyze students' academic performance, career development, risk levels, and placement outcomes.

The project uses Python-based data analysis libraries to transform student data into meaningful insights and presents the results through an interactive Streamlit dashboard.

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze student academic performance.
- Study the relationship between attendance, study hours, and final percentage.
- Analyze the impact of projects and certifications on placement outcomes.
- Analyze student placement rates and average packages.
- Identify students according to different risk levels.
- Provide an individual student performance profile.
- Provide an interactive What-If performance simulator.
- Allow users to filter and download student data.

## 🔍 Project Features

### 1. 📌 Performance Overview

The dashboard displays important Key Performance Indicators (KPIs):

- Total Students
- Average Final Percentage
- Average Attendance
- Placement Rate
- High-Risk Students
- Average Placement Package

---

### 2. 📚 Academic Performance Analytics

The dashboard analyzes:

- Average performance by department
- Placement status
- Attendance vs Final Percentage

These visualizations help identify patterns in academic performance.

---

### 3. 💼 Career & Placement Analytics

The project analyzes:

- Projects vs Placement Rate
- Certifications vs Placement Rate
- Average Package by Department
- Placement Rate by different student groups

This section provides insights into career preparation and placement outcomes.

---

### 4. 🚨 Student Risk Analysis

Students are classified into:

- Low Risk
- Medium Risk
- High Risk

The dashboard also compares risk levels with students' final percentage.

---

### 5. 👤 Individual Student Profile

Users can select an individual student and view:

- Department
- Semester
- Attendance
- Final Percentage
- Backlogs
- Projects
- Certifications
- Coding Hours
- Internship
- Placement Status
- Package
- Risk Level
- Interview Score

---

### 6. 🔮 What-If Performance Simulator

The dashboard provides an analytical What-If simulator.

Users can change:

- Attendance
- Study Hours Per Day

The dashboard then calculates an estimated performance scenario based on predefined assumptions.

> **Note:** The What-If simulator is an analytical simulation and is not a guaranteed prediction of academic performance.

---

### 7. 🔎 Interactive Filters

Users can filter the dashboard based on:

- Department
- Semester
- Gender
- Internship
- Risk Level

All major dashboard results update according to the selected filters.

---

### 8. 📥 Data Download

Users can view the filtered student records and download the filtered dataset as a CSV file.
